# CoC CCFOLIA TOOLS

ココフォリアの HTML ログから、キャラクターごとに成功した技能を集計し、上達チェックする SPA。

公開先: https://liesegang.github.io/coc-ccfolia-tools/

## 使い方

1. ココフォリアから出力した HTML ログをドロップ、またはファイル選択で読み込みます。複数ファイルに対応しています。
2. キャラクターを選び、技能値を確認します。技能名を開くと成功した判定の原文を確認できます。
3. 成長対象にする技能を選択し、個別、または選択中のキャラクターを一括で上達チェックします。
4. 全キャラクターの結果をコピー、またはテキスト保存します。

ログはブラウザ内で処理し、サーバーへの送信やブラウザへの永続保存は行いません。再読み込みすると入力・結果は消えます。付属のサンプルは架空のデータです。実際のセッションログはリポジトリや公開サイトに含めません。

## 集計と判定

- CoC の CC / CCB / 1D100 判定に対応。成功・ハード成功・イクストリーム成功・決定的成功・スペシャルなど、出力された成功結果を使用します。
- 同名キャラクターの同名技能を統合します。成功が複数回あっても上達チェックは1回です。完全に同じ内容のファイルは SHA-256 で重複を検出します。部分的に重なるログは別々に集計するため、重複部分の成功回数は増えます。
- 名前のない判定はスキップして件数を表示します。キャラクター名・技能名の表記揺れは自動的には統合しません。
- 現在の技能値の初期値は、読み込んだファイル順で最後に現れた判定の目標値です。時刻順の並べ替えは行いません。補正や難易度を含む可能性があるため、実際の技能値を確認してください。複数の値がある技能には注意表示を出します。
- SAN・能力値・幸運・アイデア・知識・クトゥルフ神話・信用は成長対象から除外し、別枠に表示します。信用の除外は7版を想定しています。
- 1D100 が技能値を上回る、または96以上で成長し、1D10を加算します。乱数には Web Crypto を使用します。
- 卓独自の成長ルール、幸運の消費・プッシュ等による成長可否、技能90%到達時の追加処理は自動判定しません。対象のチェックを外すなど、キーパーの判断に合わせて調整してください。
- UTF-8 / Shift JIS、1ファイル20MBまで。HTMLを画面に挿入せず、抽出した文字列のみを表示します。

技能成長の概要: [Chaosium — Rewards of Success](https://cthulhuwiki.chaosium.com/rules/rewards-of-success.html)。本ツールは非公式です。

## 開発

Node.js 22以降を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

React + Vite。GitHub Actions でテスト・ビルド後、`dist` のみを GitHub Pages へ公開します。Pages の Source は GitHub Actions に設定します。

[GitHub Pages のカスタムワークフロー](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)に準拠しています。
